# 我的记账本 · MyJizhang

本地优先的 Android 记账应用。无账号、无广告、无网络依赖，账目全部存在设备本地，导出的 Excel 可以直接和一飞记账互通。

> 这个项目起因于一飞记账停止运营：手里有一份导出的 xlsx，但找不到能把它完整接过来的工具。于是先做了「能导入」，再逐步把记账、资产、借款、预算、报表补齐。

## 功能

**账单**
- 按月切换，当月收入 / 支出 / 结余概览，流水按日分组
- 支出、收入、转账三类记账，支持退款、报销、手续费
- 左滑删除，弹窗二次确认，确认后余额同步回滚
- 两级分类（大类 + 小类），大类不污染记账网格

**日历**
- 月历视图，每天显示收支合计，点开看当日明细

**资产**
- 四个分组：信贷 / 充值 / 资金 / 投资理财
- 净资产拆成四个口径：**可支配 / 投资 / 应收 / 负债**
- 信用卡支持额度、出账日、还款日
- 账户流水、对账调整流水

**借款**
- 借入 / 借出分开管理，按人 FIFO 冲销还款，支持部分还款
- 还款只冲销「同一个人」名下的借款，多还的钱不会去抵别人的账

**统计**
- 分类占比与金额排行
- 财务健康：结余率、固定 vs 弹性支出、预算执行进度
- 预算支持按月总额 + 分类预算

**设置**
- 多账本管理
- Excel 导入 / 导出
- GitHub 仓库备份（可选 AES-256-GCM 加密）

## 财务口径

这是本项目与普通记账 App 差别最大的地方，所有数字都遵循同一组不变式：

```
账户余额 = 期初余额 + 账单流水 + 对账调整
净资产   = 可支配 + 投资 + 应收借出 − 负债（账户欠款 + 未还借入）
支出     = 金额 − 退款 − 已报销        （转账手续费计入支出）
结余率   = 结余 ÷ 收入
```

几个刻意的设计：

- **余额不是累加出来的，而是有期初的**。老账本迁移时不必从 0 重新累加，填入真实余额即可反推期初。
- **借出是资产，不是损失**。借出时账户余额已经减少，如果不把应收加回来，借钱当天净资产会凭空缩水；还款时又会凭空回涨。
- **借入必须在负债里体现**，否则借钱当天净资产反而变大。
- **还款只冲同一个人**。历史上出现过「多还的 500 被摊到另一个人的借出上」，导致无辜的人显示「部分已还」。

## Excel 导入 / 导出

导出包含 5 个 sheet：

| Sheet | 说明 |
|---|---|
| 支出 / 收入 / 转账 | 列名与列顺序和一飞记账逐字一致，可双向互导 |
| 账户 | 账户名、类型、分组、余额、额度、期初余额（原版会忽略） |
| 对账 | 时间、账户、调整额、原因、调整后余额（原版会忽略） |

导入时的行为：

- 按 sheet 名匹配（含「支出 / 收入 / 转账」即读），其他 sheet 自动跳过
- 兼容不补零日期（`2026-11-6 16:27`）、千分位金额（`1,5253.46`）
- 账户 / 分类缺失自动创建，名称含「信用卡 / 花呗」自动建为信用账户
- 去重指纹为「类型 + 时间 + 金额(分) + 账户 + 备注」，同一份文件导两次不会金额翻倍
- 债务类分类（借出 / 借入 / 收款 / 还款）会自动推导借款记录并按人冲销

## 导入迁移向导

从旧 App 迁过来时，四步把账搬平：

1. **体检**：读文件，统计笔数、时间跨度、账户与分类
2. **认领账户**：填今天的真实余额，系统反推期初
3. **整理分类**：标注固定 / 弹性 / 不计收支，指定所属大类
4. **稽核**：逐账户输出「期初 + 流水 = 期末」，对不上会标红

## 技术栈

- Kotlin + Room（SQLite），数据库版本 7，迁移链 `1→2→3→4→5→6→7`
- 单 Activity + 5 个 Fragment，ViewBinding，Material 3
- 协程 + Flow 驱动 UI，DAO 直接暴露 `Flow`
- xlsx 读写为自研实现（`java.util.zip` + `XmlPullParser`），未引入 Apache POI，APK < 6 MB
- 备份加密：AES-256-GCM，PBKDF2 派生密钥，文件头 `MJZ1`

### 数据表

| 表 | 作用 |
|---|---|
| `AccountBook` | 账本 |
| `Category` | 分类（含 `parentId`、`nature` 固定/弹性/不计收支） |
| `Asset` | 账户（含 `openingBalance` 期初、`inTotalAsset` 是否计入净资产） |
| `Bill` | 账单流水（支出/收入/转账） |
| `Loan` | 借入/借出（含 `repaidAmount` 已还、`imported` 来源标记） |
| `Adjust` | 对账调整流水 |
| `Budget` | 预算（`month=""` 表示按月循环） |

## 构建

要求：JDK 17、Android SDK Platform 34、Build-Tools 34。

```bash
./gradlew assembleRelease
```

首次运行会自动下载 Gradle 8.4。也可以直接用 Android Studio 打开。

APK 输出在 `app/build/outputs/apk/release/`。

### 签名

签名信息不写进仓库，放在 `local.properties`（已在 `.gitignore` 中）：

```properties
sdk.dir=/path/to/android/sdk

RELEASE_STORE_FILE=release.keystore
RELEASE_STORE_PASSWORD=******
RELEASE_KEY_ALIAS=myjizhang
RELEASE_KEY_PASSWORD=******
```

缺省时 `assembleRelease` 会产出未签名包，仅用于本地调试。

## 隐私

- 无网络权限以外的数据上传，账目只存在本机 SQLite
- GitHub 备份由你提供 Token，可选加密，Token 只存手机本地
- 没有埋点、没有统计 SDK

## 已知限制

- 两级分类目前只服务报表，记账页仍是单层
- 「账户」sheet 导出的是当前余额，不按月切片
- 去重指纹包含备注，极端情况下同分钟、同金额、同账户、同备注的两笔会被误合并
- 借款的「人」取自备注，备注为空时用分类名兜底，同人不同写法（如「蒋」「蒋浩鹏」）不会自动合并
